Claude Code holds a function. Codex tries to change it. LangSpan tells Codex about the other session and refuses the overlapping edit.

```text
Command blocked by PreToolUse hook: LangSpan coordination conflict.
```

LangSpan adds shared awareness, code-aware coordination and integration checks to the coding agents you already run. The excerpt is from a [recorded Codex session](https://github.com/Langspan/LangSpan.dev/blob/main/docs/evidence/codex-real-host/README.md#2-a-conflicting-edit).
