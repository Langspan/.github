# Your agents. On the same page.

LangSpan keeps a team's coding agents informed about each other's work. It
brings relevant updates into their existing sessions so developers can work on
connected parts of a feature without relaying every change by hand.

Our mission is to help teams keep building together as their agents write more
code. People set direction and review the combined result.

LangSpan connects through native hooks, CLI and MCP. An optional dashboard
shows the recorded work. One developer running several agents can use the
same tools.
